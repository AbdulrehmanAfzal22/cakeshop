# Cakes Galaxy

A responsive React storefront for showcasing custom celebration cakes from Cakes Galaxy in Lahore.

## Requirements

- Node.js 18 or newer
- npm

## Development

```sh
npm install
npm run dev
```

Vite prints the local development URL after startup.

## Production build

```sh
npm run build
npm run preview
```

## Project structure

```text
public/assets/       Cake photography, logo, and local fonts
src/components/      Page sections and reusable UI components
src/data/catalog.js  Cake designs and collection categories
src/App.jsx          Main page composition and design dialog state
src/main.jsx         React entry point
src/styles.css       Responsive site styles
```
